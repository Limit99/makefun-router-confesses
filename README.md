# The Microwave Asked

A tiny Node/TypeScript program for the make.fun bounty "The Router Confesses". It writes one funny single-line confession to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of under 200 characters in which the router excuses itself for dying at the climax of a movie.

Entry line:

> I am sorry I died during the final scene — the microwave asked me to hold its beer, and I have never been the same since.

Run it with: `node main.ts`
